# Godot Math GameDev Persona

Este plugin adiciona ao DeepSeek Harness um persona especializado em:

- Desenvolvimento de jogos para celular
- Godot 4 (GDScript moderno)
- Arquitetura limpa e modular
- Design para celular
- UI/UX para jogos infantis e adultos
- Estruturação de cenas, nós e sistemas de perguntas

## Como usar

1. Abra o DeepSeek Harness.
2. Vá em **Plugins**.
3. Clique em **Add Plugin**.
4. Selecione a pasta `godot_math_gamedev_persona`.
5. Ative o plugin.
6. Escolha o persona **GodotCellGameDev** como preset.

Agora, sempre que você fizer um pedido, o modelo responderá como um especialista em Godot focado em jogos de celular.
